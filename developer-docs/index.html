About this site

This is a static documentation site served from the repository's /docs folder via GitHub Pages (a .nojekyll marker keeps the hand-authored HTML/assets untouched). Every page is generated against the live main tree — route values, @Modal status, module dependencies, and navigation flows were read from source, not assumed. The in-repo markdown spine (ROADMAP, MVP, sprint archives) remains the canonical planning record.
