Kids Mode

Purpose Functionality Dependencies Navigation flow

Kids Mode (Дитячий світ) is a simplified, palette-themed prayer experience for children 7+ — softer pastel chrome, fewer affordances, and a saint-companion home, entered behind a Settings row and re-themed by one of three iconographically-coded palettes (Rose / Meadow / Sky).

Purpose

Kids Mode is a curated, gentler corner of Molytovnyk aimed at children 7+ and newcomers. Where the adult Home carries streak math, a parish strip, and a candle triptych, the kids surface deliberately keeps only what a child needs: who you are (a name-driven greeting), who is praying with you (a patron-saint companion), what to do today (one short morning-prayer task), and how this week looks so far (a row of lit/unlit candles).

The visual language softens too — pastel cards float on rounded surfaces, the chrome is warmer, and copy is written in child-voice Ukrainian. The mode is themed by one of three palettes, each tied to iconographic pigment so the choice carries meaning rather than being a plain color swap:

  • Троянда / Rose — Theotokos warmth, the dusty rose of the Богородиця’s мафорій.
  • Лука / Meadow — monastic Carpathian green, the sage of the преподобні.
  • Небо / Sky — angelic lapis, the faded blue of icon backgrounds.
Distinct from the V1 KidsThemeColor enum (PINK / BLUE / GREEN / ORANGE / PURPLE), which targets the legacy surfaces. The V2 redesign uses the three richer KidsPalette entries above.

Functionality

The module ships two screens plus a theming wrapper, each screen split into a Koin-wired *Route (state + navigation) and an internal stateless *Screen (pure UI, Paparazzi- and preview-friendly).

  • KidsThemePickerScreen (KidsThemePickerRoute + KidsThemePickerViewModel) — the one-shot setup screen. It renders a card per KidsPalette.entries (Троянда / Лука / Небо) with a preview swatch, pigment label, and description. Tapping a card calls viewModel.confirm(palette), which persists the choice via setKidsPaletteName(palette.name) and idempotently flips setKidsMode(true); state.confirmed then flips and a LaunchedEffect fires onPicked so navigation only happens after the write lands. The picker itself sits on the dark Byzantine page (MolytovnykThemeV2(darkTheme = true)) with the pastel cards floating on top.
  • KidsHomeScreen (KidsHomeRoute + KidsHomeViewModel) — the palette-driven home. Composed of an app-bar date/feast line, a name greeting block (avatar initial + line), a tappable saint card, a morning-prayer task card, a 7-day candle week strip, an optional next-feast countdown, a “shake to greet your Angel” hint, and bottom actions (Змінити тему / Дорослий режим). KidsHomeViewModel binds real data (Wave RR.3 K4): the greeting name from the displayName preference, the patron saint from the name-driven AngelDayService chain (with graceful name-less fallback copy), and the week candles from StreakRepository.lastWeek (a day lights when any prayer slot was completed). Palette and greeting both ride the prefs flow, so a profile-name edit or a re-pick re-themes the screen live. The task / next-feast remain placeholders for a later phase.
  • KidsThemeContainer — a deliberately dumb, Koin-free wrapper that calls MolytovnykThemeV2(kidsPalette = palette) around its content. KidsHomeRoute wraps the home in it so the adult navigation theme doesn’t leak in. Each screen owns palette resolution in its own ViewModel (read from UserPreferences.kidsPaletteName via KidsPalette.parse, defaulting to ROSE).

The whole surface is Paparazzi-covered since Wave KV.1 (#1000) — picker + Kids Home across all three palettes × light/dark — so any :core:designsystem token change that would silently break Kids Mode is caught.

Navigation flow

Kids Mode is not a bottom-nav tab and not a sub-state of the adult Home — it is a pair of full-screen @Modal routes reached deliberately from Settings. A parent (or child) taps the “Дитячий світ” SettingsNavRow; SettingsRoute’s onEnterKidsMode navigates to kids/picker.

The picker is a one-shot setup: confirming a palette persists kidsPaletteName + sets kidsMode = true, then navigates to kids/home while popping the picker off the back stack (popUpTo(KidsPicker){ inclusive = true }) — so Back from Kids Home does not land on the picker. The picker’s own Закрити simply pops back to Settings without committing.

Because both routes are @Modal (KSP-collected into MODAL_ROUTES), the bottom navigation bar is hidden throughout — reinforcing the “separate corner” feel. From Kids Home: the task CTA opens prayer/morning (the short morning routine), the saint card opens the Angel-Day browser, Змінити тему re-opens the picker, and Дорослий режим (exit) calls viewModel.exitKidsMode() (which sets kidsMode = false) and navigates back to the adult Home, popping the kids stack.

Entering the picker flips kidsMode on only when a palette is confirmed; closing the picker without picking leaves the preference untouched. Exit from Kids Home is the canonical way back to the adult app and explicitly clears the flag.
